# Pull request workflow

Use this sandbox to practice a small documentation change from branch to merge.

1. Create a branch from the default branch.
2. Make a documentation change and check the diff.
3. Open a pull request describing the change.
4. For the YOLO achievement exercise, have the pull request author merge it without a code review.
5. Check the merged pull request and the author's achievement page.

GitHub controls achievement eligibility and award timing. A successful merge does not guarantee that a badge will appear immediately.

For a future Pair Extraordinaire exercise, work with another contributor and credit their actual contribution using the email associated with their GitHub account. Include a correctly formatted `Co-authored-by` trailer in the commit that is merged.

For a future Galaxy Brain exercise, answer two Q&A discussions opened by other users and have the answers accepted. Self-authored discussions should not be relied on to qualify. Acceptance depends on the question author or a maintainer.
